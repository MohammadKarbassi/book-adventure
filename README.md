# ماجراجویی با کتاب (Book Adventure)

«ماجراجویی با کتاب» یک فروشگاه فارسی و راست‌به‌چپ برای کتاب الکترونیکی، کتاب صوتی و پادکست است که برای بوت‌کمپ مهندسی هوش مصنوعی ساخته شده. صفحهٔ اول، قفسه‌ای سه‌بعدی از کتاب‌های منتخب به سبک Stripe Press است و پشت آن یک فروشگاه کامل قرار دارد: دسته‌بندی و جستجو، صفحهٔ کتاب به رنگ جلد، خرید و اشتراک آزمایشی، کتاب‌خوان با ورق زدن و پخش‌کنندهٔ صوتی سراسری. حدود ۱۱۰ کتاب واقعی از فیدیبو و ۱۰ پادکست فارسی در سایت هست و همهٔ داده‌های کاربر در مرورگر خودش می‌ماند.

## امکانات

**ورودی سینمایی**

- با هر بار باز کردن یا بارگذاری مجدد صفحهٔ اصلی، جمله‌ها کلمه‌به‌کلمه و از راست به چپ ظاهر می‌شوند: «هر کتاب، یه کشف تازه...»، «یه ماجراجویی جدید»، «ماجراجویی با کتاب» و «Book Adventure». رفت‌وآمد داخلی در همان بارگذاری، ورودی را تکرار نمی‌کند.
- موسیقی کوتاه و اختصاصی با ریتم ماجراجویانه داخل مرورگر ساخته می‌شود. اگر مرورگر صدای خودکار را مسدود کند، دکمهٔ «پخش موسیقی» صدا را فعال می‌کند؛ با پایان یا رد شدن ورودی، صدا قطع می‌شود.
- یک لایه روی صفحهٔ اصلی است؛ دکمهٔ «رد شدن» دارد و هر کلیک یا کلیدی آن را تمام می‌کند.
- تصمیم نمایش پیش از اولین paint گرفته می‌شود تا بازدیدکنندهٔ تکراری چشمکی نبیند؛ با `prefers-reduced-motion` کاملاً رد می‌شود.

**صفحهٔ اصلی و قفسهٔ سه‌بعدی (با الهام از Stripe Press)**

- حدود ۲۰ کتاب منتخب، خوابیده و روی هم، با CSS سه‌بعدی و motion؛ عطف هر کتاب به رنگ جلد آن است و عنوان و نویسنده را نشان می‌دهد.
- قفسه با اسکرول کمی می‌چرخد؛ با hover، کتاب بالا می‌آید و قیمتش دیده می‌شود؛ با کلیک به صفحهٔ کتاب می‌رود.
- نوار فهرست باریک کنار قفسه.
- زیر قفسه: دسته‌بندی‌ها، ردیف‌های پرفروش‌ها، تازه‌ها، تخفیف‌ها، کتاب‌های صوتی و کتاب‌های اشتراکی، معرفی اشتراک و پادکست‌ها.

**دسته‌بندی‌ها و جستجو**

- منوی دسته‌ها در هدر، صفحهٔ همهٔ دسته‌ها و صفحهٔ هر دسته با فیلتر زیردسته، نوع (الکترونیکی/صوتی)، مرتب‌سازی (پرفروش‌ترین، امتیاز، قیمت، تخفیف) و صفحه‌بندی؛ وضعیت فیلترها در آدرس صفحه می‌ماند.
- جستجوی سریع با `⌘K` / `Ctrl+K` یا `/` و صفحهٔ کامل نتایج با برجسته‌کردن کلمهٔ جستجو، فیلتر نوع و نتایج پادکست.
- جستجو حروف عربی و فارسی (ي/ی، ك/ک)، اعراب، نیم‌فاصله و رقم‌های فارسی را یکسان در نظر می‌گیرد.

**صفحهٔ کتاب**

- پس‌زمینه به رنگ غالب جلد و جلد سه‌بعدی که هنگام اسکرول ثابت می‌ماند.
- گزینه‌های خرید جدولی، قیمت با تخفیف و قیمت نسخهٔ چاپی، مشخصات کتاب و خلاصهٔ امتیازها.
- خرید آزمایشی با پنجرهٔ «کتاب خریداری شد» و افزودن به «کتابخانهٔ من».
- افزودن به علاقه‌مندی‌ها و اشتراک‌گذاری.
- نظرهای فیدیبو در کنار نظرهای خود کاربر (فرم با امتیاز ستاره‌ای).
- کتاب‌های مشابه.

**کتاب‌خوان**

- ورق زدن شبیه کتاب واقعی با کلیک، کلیدهای جهت‌نما و کشیدن صفحه؛ روی دسکتاپ دو صفحه کنار هم و روی موبایل تک‌صفحه.
- صفحهٔ اول جلد کتاب، صفحهٔ دوم معرفی همان کتاب و بعد متن نمونهٔ آزاد از گلستان سعدی.
- تغییر اندازهٔ متن و رنگ صفحه، و ذخیرهٔ صفحهٔ فعلی.
- در حالت نمونه، بعد از چند صفحه پیام «برای خواندن ادامهٔ کتاب، آن را بخرید یا اشتراک بگیرید» با دکمه‌های خرید و اشتراک نمایش داده می‌شود.

**کتاب صوتی و پادکست**

- صفحهٔ جدا برای کتاب‌های صوتی و پادکست‌ها، و صفحهٔ هر پادکست با اپیزودهایش.
- پخش‌کنندهٔ سراسری پایین صفحه که با رفتن به صفحه‌های دیگر قطع نمی‌شود: سرعت پخش (۰٫۷۵ تا ۲ برابر)، ۱۵ ثانیه جلو و عقب، نوار پیشرفت و ادامه از جای قبلی.
- کنترل از کلیدهای رسانه‌ای سیستم (Media Session).

**اشتراک**

- گزینهٔ «اشتراک» در منو و صفحهٔ طرح‌ها (یک‌ماهه، سه‌ماهه، یک‌ساله) با فعال‌سازی آزمایشی و پرسش‌های پرتکرار.
- با اشتراک فعال، کتاب‌های اشتراکی (`in_plus` در دادهٔ فیدیبو) بدون خرید باز می‌شوند و بقیه همچنان خرید لازم دارند.

**کتابخانهٔ من**

- سه زبانه: خریده‌شده‌ها، علاقه‌مندی‌ها و کتاب‌های اشتراکی، با حالت خالی برای هر کدام.

**حالت تیره و RTL**

- حالت تیره بر اساس تنظیم سیستم و جابه‌جایی با کلید `d` یا دکمهٔ هدر.
- رابط کاملاً راست‌به‌چپ با کلاس‌های منطقی Tailwind، رقم‌ها و قیمت‌های فارسی، و واکنش‌گرا برای موبایل.

## فناوری‌ها

- Next.js 16.4 (App Router) و React 19
- TypeScript (حالت strict)
- Tailwind CSS v4 (بدون `tailwind.config`)
- shadcn/ui روی Base UI؛ کامپوننت‌های اصلی: Button، Badge، Card، Dialog، Sheet، Tabs، Tooltip، Command، Navigation Menu، Dropdown Menu، Toggle Group، Item، Empty، Skeleton، Spinner، Progress، Slider، Field، Input Group، Textarea، Radio Group، Accordion، Carousel، Breadcrumb، Pagination، Scroll Area، Kbd، Avatar و Sonner
- motion برای انیمیشن‌ها
- next-themes برای حالت تیره
- lucide-react برای آیکون‌ها
- Vitest برای تست واحد و Playwright برای تست مرورگر

## داده‌ها

- سایت بک‌اند، دیتابیس و ورود/ثبت‌نام ندارد؛ همهٔ داده‌ها فایل‌های JSON ثابت در پوشهٔ `data/` هستند و سایت هنگام اجرا به فیدیبو درخواست نمی‌فرستد.
- **کتاب‌ها:** ۱۱۲ کتاب فارسی (الکترونیکی و صوتی) در ۸ دستهٔ اصلی، یک بار با MCP غیررسمی فیدیبو ([fidibo-mcp](https://github.com/sepehr071/fidibo-mcp)) جمع‌آوری شده‌اند؛ رنگ غالب هر جلد هم در همین مرحله استخراج می‌شود. اسکریپت: `scripts/fetch-fidibo.mjs` (نیاز به `uv` دارد).
- **پادکست‌ها:** ۱۰ پادکست فارسی که با iTunes Search پیدا شده‌اند و اپیزودهایشان از فیدهای عمومی RSS خوانده شده است. اسکریپت: `scripts/fetch-podcasts.mjs`.
- **صدای کتاب‌های صوتی:** نمونه‌های آزاد از Internet Archive (هزار و یکشب و Farsi Readings با صدای Soheil Solhjoo با مجوزهای CC BY-NC-ND 4.0 و CC BY-NC-SA 4.0، و مثنوی معنوی با صدای Iraj Shahbaz در مالکیت عمومی). مجوز و منبع هر فایل در `data/audio-samples.json` ثبت شده است.
- **دادهٔ کاربر:** علاقه‌مندی‌ها، خریدها، اشتراک، نظرها، صفحهٔ فعلی کتاب‌خوان، جای پخش صدا در localStorage با پیشوند `book-adventure:v1:` ذخیره می‌شوند، بدون خطای hydration.

به‌روزرسانی داده‌ها:

```bash
npm run data:fidibo
npm run data:podcasts
```

## اجرا

```bash
npm install
npm run dev
```

سپس <http://localhost:3000> را باز کنید. نسخهٔ تولید:

```bash
npm run build
npm start
```

بررسی کد:

```bash
npm run lint
npm run typecheck
```

## تست‌ها

بیش از ۱۵۰ تست واحد با Vitest برای منطق خالص (قالب‌بندی فارسی، ذخیره‌سازی، دسترسی و اشتراک، فیلتر و جستجو، قفسه، ورودی سینمایی، پخش‌کننده و کتاب‌خوان):

```bash
npm test
```

تست‌های مرورگر با Playwright؛ نسخهٔ تولید را می‌سازد، روی پورت 3100 اجرا می‌کند و در دو پروژهٔ دسکتاپ (۱۴۴۰×۹۰۰) و موبایل (Pixel 7) تست می‌گیرد:

```bash
npm run test:e2e
```

برای اجرای تست‌ها روی سروری که از قبل در حال اجراست (مثلاً سرور توسعه):

```bash
E2E_BASE_URL=http://localhost:3000 npm run test:e2e
```

## نکته‌ها

- خرید و اشتراک شبیه‌سازی‌اند؛ هیچ پرداختی انجام نمی‌شود و نتیجه فقط در مرورگر شما ذخیره می‌شود.
- تصویر جلدها مستقیم از CDN فیدیبو بارگذاری می‌شود.
- این پروژه آموزشی است و ارتباطی با فیدیبو ندارد. حق اطلاعات و جلد کتاب‌ها با فیدیبو و ناشران است، حق پادکست‌ها با سازندگانشان و حق فایل‌های صوتی با گویندگانشان طبق مجوز هر فایل.
- متن نمونهٔ کتاب‌خوان از گلستان سعدی (مالکیت عمومی) است.
