# Adventure cover provenance

These 14 cover thumbnails are local WebP derivatives of the project's existing Fidibo catalog covers, taken from `.cache/covers/<bookId>.img` and identified by `data/catalog.json` (`books[].id`, `books[].image`). They are not Stripe images or textures. Conversion: Sharp, maximum width 720px, WebP quality 85, no enlargement. Original catalog image URLs and bibliographic attribution remain in `data/catalog.json`.

The WebGL hardcover geometry, paper-edge texture, back and spine maps are generated by `components/adventures/adventure-scene.tsx`. They are temporary project-authored substitutes: no scanned back cover, bump, foil, gloss or proprietary Stripe model is available. Front covers use the existing catalog artwork.
